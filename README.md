## Declarative UI

## ✅ Features
- Add Commands/Menus/Containers, all with simple .json files in a datapack

## 📖 Usage
- Use `/item <modify/replace> container` in order to modify a player stored container
- Search for Declarative UI Generators on [Misode's Modded Generators](https://misode.github.io/partners/)
- Make sure to put your json files into `data/<namespace>/declarative_ui/[command/menu/container]`
